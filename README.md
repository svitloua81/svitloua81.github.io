# SvitloUA — Official Website

Public website for the **SvitloUA** (СвітлоUA) Android app — power outage schedules for Ukrainian
regions, by Alex Hrindii. Built for GitHub Pages; all links are relative, so the site works both at a
domain root and inside a sub-folder (e.g. `https://possible1770.github.io/svitloua/`).

Package: `com.icompany.svitloua`

## Pages
- `index.html` — landing page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms & Conditions
- `app-ads.txt` — AdMob authorized sellers file (IAB Tech Lab spec)

## app-ads.txt
Must be served at the **root** of the domain listed as the developer website in Google Play
(e.g. https://possible1770.github.io/app-ads.txt). The publisher id is the same as for OBook
(`pub-1850870377158539`), so if SvitloUA lives in a sub-folder of the same Pages site, the root file
already covers it and this copy can be dropped.
